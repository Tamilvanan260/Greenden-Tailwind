# 🌿 Greenden — Responsive E-Commerce UI

A clean, modern, and high-performance front-end user interface for a plant shop web application. Designed using semantic HTML5 and utility-first styling with Tailwind CSS.

---

## ⚡ Overview

**Greenden** is built to showcase a seamless e-commerce UI flow across multiple pages. The focus was on component-driven layout architecture, mobile-first responsiveness, and smooth visual interactive states.

### 🔍 Key Features

* 📱 **Mobile-First Responsive Design:** Dynamic navigation and grid layouts scaling seamlessly across mobile, tablet, and desktop viewports.
* ⚡ **Tailwind CSS Utility Engine:** Styled with custom flex/grid structures, hover transformations (`-translate-y`), focus states, and shadow effects.
* 🛍️ **Multi-Page Architecture:**
* `index.html` — Hero banner, brand value propositions, bestsellers grid, and customer testimonials.
* `product.html` — Full product catalog with styled product frames and interactive hover animations.
* `contact.html` — Fully styled user enquiry form with focused field states.
